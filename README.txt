리디북스 가이드 자동 점검·교정 대시보드

실행 방법
1. 이 폴더의 '리디가이드대시보드_실행.bat'을 더블클릭합니다.
2. 브라우저에서 http://localhost:8765 주소가 열립니다.
3. 편집팀 원문을 붙여넣고 '검사하고 자동 교정'을 누릅니다.

현재 적용 규칙
- 필수 항목 6개 누락 및 빈값 검사
- 로맨스/로판/섹슈얼로맨스는 남자주인공·여자주인공 항목 사용
- 원문에 공 또는 수가 있으면 BL 양식으로 판단
- BL 양식에서는 남자주인공·여자주인공을 삭제하고 공·수로 출력
- 배경/분야의 슬래시(/) 앞뒤 공백 제거
- 작품 키워드의 세미콜론(;)을 쉼표(,)로 변경
- 원문의 줄바꿈과 빈 줄 유지
- 키워드 쉼표 뒤 공백 통일
- 양식 바깥 문구 제외 및 경고
- 중복 항목 경고
