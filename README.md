# 리디 가이드 점검기

편집팀에서 전달받은 작품 가이드를 리디 접수양식에 맞게 점검하고 자동 교정하는 정적 웹 대시보드입니다.

## 주요 기능

- 접수양식 필수 항목 6개 누락·빈값 검사
- 로맨스·로판·섹슈얼로맨스는 `남자주인공/여자주인공` 항목 사용
- 원문에 `공` 또는 `수` 항목이 있으면 BL 양식으로 자동 판단
- BL 양식에서는 `남자주인공/여자주인공`을 제거하고 `공/수`로 출력
- `배경/분야`의 슬래시(`/`) 앞뒤 공백 제거
- `작품 키워드`의 세미콜론(`;`)을 쉼표(`,`)로 변환
- 원문에 입력된 줄바꿈과 빈 줄은 그대로 유지
- 중복 항목과 양식 외 문구 경고
- 수정 전·후 비교 및 제출용 교정본 복사

## 개인정보 및 원문 처리

입력한 작품 가이드 원문은 서버로 전송하거나 저장하지 않습니다. 모든 점검과 교정은 사용자의 브라우저 안에서만 수행됩니다.

## 로컬 실행

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다.

## 테스트

```bash
node tests.mjs
```
